This installation runs SyncTV, PostgreSQL, and Redis on one host. For Kubernetes, use the [Helm installation](../../install/helm/).

## Prerequisites

- Docker and Docker Compose are available.
- GNU Make and `openssl` are available for the env initializer.
- A durable working directory for the Compose files, three env files, and data volumes.
- An initial root password generated by a password manager.

## Install

<Steps>
1. Get the production Compose configuration:

   <Code
     code={[`git clone --depth 1 ${githubCloneUrl} synctv`, 'cd synctv'].join('\n')}
     lang="bash"
   />

2. Generate `.env.postgres`, `.env.redis`, and `.env.synctv`:

   ```bash
   make compose-init
   ```

3. Edit `.env.synctv` and set the root password:

   ```dotenv
   SYNCTV_BOOTSTRAP_ROOT_PASSWORD=replace-with-a-strong-password
   ```

4. Validate the rendered Compose config:

   ```bash
   make compose-config
   ```

5. Start the services in the background:

   ```bash
   make compose-up
   ```
</Steps>

## Verify

Inspect the containers and request the readiness endpoint:

```bash
make compose-ps
curl -fsS http://localhost:8080/health/ready
```

After the readiness request succeeds, open:

```text
http://localhost:8080
```

Sign in as `root` with the `SYNCTV_BOOTSTRAP_ROOT_PASSWORD` value from `.env.synctv`.

## Back Up Data and Secrets

Back up PostgreSQL and store these values in a password manager or secret management system:

| Environment variable | Purpose |
| --- | --- |
| `SYNCTV_JWT_SECRET` | Signs access, refresh, and guest tokens |
| `SYNCTV_SECURITY_OPAQUE_SERVER_SETUP_SECRET` | Long-lived server secret for OPAQUE password authentication |
| `SYNCTV_SECURITY_CREDENTIAL_ENCRYPTION_KEY` | Encrypts Provider credentials |
| `SYNCTV_BOOTSTRAP_ROOT_PASSWORD` | Creates the initial root user |

<Aside type="caution">
Keep the secrets in `.env.synctv` for the lifetime of the installation. Existing password records depend on the OPAQUE secret, and Provider credentials depend on the credential encryption key.
</Aside>

## Common Failures

| Symptom | Action |
| --- | --- |
| `make compose-config` reports missing variables | Run `make compose-init` and keep `.env.postgres`, `.env.redis`, and `.env.synctv` in the current directory. |
| `/health/ready` fails | Run `make compose-logs SERVICE=synctv` and inspect the first startup error. |
| Browser CORS errors | Set `SYNCTV_SERVER_CORS_ALLOWED_ORIGINS` in `.env.synctv`; use origins only. |
| Root user cannot log in | Confirm `SYNCTV_BOOTSTRAP_ROOT_PASSWORD` was set before first database startup and inspect bootstrap logs. |
