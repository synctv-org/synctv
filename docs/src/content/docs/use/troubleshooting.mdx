---
title: 用户排障
description: 普通用户按现象定位登录、房间、播放、聊天、媒体和通知问题，并收集有效信息。
---

先按现象定位，再决定是否联系房间管理员或平台管理员。提交问题时只提供必要信息，不要发送密码、token、Cookie、Provider 凭据、OAuth2 code 或验证码。

## 快速定位

| 问题 | 先检查 | 交给谁 |
| --- | --- | --- |
| 登录失败 | 用户名密码、邮箱验证、2FA、账号是否被封禁 | 平台管理员 |
| OAuth2 后没有登录 | 是否进入注册审核、第三方账号是否已绑定 | 平台管理员 |
| 加不进房间 | 房间密码、审核状态、是否被房间封禁、人数上限 | 房间管理员 |
| 不能控制播放 | 是否有 `control_playback_state`、`navigate_playback` | 房间管理员 |
| 播放不了 | Provider 凭据、直连 header、代理路径、上游 Range | 房间管理员或平台管理员 |
| WebSocket 总断开 | 网络、浏览器代理、反向代理超时、房间连接限制 | 平台管理员 |
| 不能聊天 | `send_chat_messages` 权限、房间聊天开关、禁言状态 | 房间管理员 |
| 收不到通知 | 通知偏好、邮箱验证、SMTP 是否启用 | 平台管理员 |

## 提交问题时提供

| 信息 | 示例 |
| --- | --- |
| 时间 | 2026-05-10 21:30 Asia/Shanghai |
| 房间或媒体 | 房间 ID、媒体名称或媒体 ID |
| 操作 | 登录、加入房间、点击播放、发送消息、添加媒体 |
| 错误 | 页面提示、HTTP 状态码、`requestId` |
| 范围 | 只有自己异常，还是多名成员同时异常 |

如果问题涉及播放，补充直连还是代理、是否 seek、是否切换媒体后出现。管理员排查生产问题时会继续使用 [排障入口](../../operations/troubleshooting/)。
