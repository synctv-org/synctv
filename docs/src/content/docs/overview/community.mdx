这页提供 SyncTV 的公开讨论入口，并展示服务端与 App 项目的贡献者。

## 参与讨论

加入 [SyncTV Telegram 讨论组](https://t.me/synctv)，交流部署、运维、播放、媒体 Provider、客户端开发和产品建议。

公开频道中的内容对其他成员可见。提交日志、截图或配置前，请移除密码、Token、Cookie、私有 URL 和个人数据。
