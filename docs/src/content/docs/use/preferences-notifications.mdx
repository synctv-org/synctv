title: 通知与个人设置
description: 普通用户如何管理通知偏好、默认 Provider、绑定方式和安全偏好。
---

个人设置只影响当前用户，不等同于实例配置。管理员可以配置平台能力，例如 SMTP、OAuth2 provider、Provider instance 和注册策略；用户设置决定你自己如何接收通知和使用这些能力。

## 常见设置

| 设置 | 影响 |
| --- | --- |
| 通知偏好 | 房间邀请、房间事件、系统公告的站内通知或邮件通知 |
| 默认 Provider | 添加媒体时默认使用的 Provider instance |
| 绑定方式 | password、passkey/WebAuthn、邮箱、OAuth2 绑定 |
| 2FA | 本地登录是否需要第二因素 |
| 邮箱状态 | 是否可接收验证、找回和 MFA 邮件 |

## 通知收不到

| 现象 | 先检查 |
| --- | --- |
| 没有邮件 | 邮箱是否验证、通知偏好是否启用、垃圾箱是否拦截 |
| 没有站内通知 | 是否关闭该类通知，是否已经读过 |
| 只有某类通知缺失 | 房间或系统是否真的触发了该事件 |
| 所有人都收不到邮件 | 管理员需要检查 SMTP 配置和邮件投递日志 |

## 安全偏好

修改登录方式前，先确认还能完成下一次登录。开启 2FA 后，不要删除到只剩一种本地验证方式。绑定 OAuth2 可以方便登录，但 OAuth2 不计入本地 2FA 因素。

账号安全细节见 [登录与账号安全](../accounts-security/)。
