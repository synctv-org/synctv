## 用户会看到的核心对象

| 对象 | 你会在哪里遇到 | 问题通常表现为 |
| --- | --- | --- |
| 账号 | 登录、个人设置、通知、安全验证 | 登录失败、2FA 不可用、邮箱未验证 |
| 房间 | 房间列表、房间入口、观影页面 | 加不进去、需要密码、等待审核 |
| 播放列表 | 房间内媒体队列 | 看不到媒体、不能添加、顺序变化 |
| 当前播放 | 播放器和同步状态 | 进度不同步、切换失败、URL 过期 |
| 聊天 | 房间侧栏 | 不能发言、消息不同步、聊天关闭 |
| Provider | 添加媒体和播放来源 | 凭据过期、直连 header 不支持、代理慢 |

更完整的产品模型见 [房间](../concepts/rooms/)、[播放模型](../concepts/playback-model/) 和 [权限模型](../concepts/permissions/)。
