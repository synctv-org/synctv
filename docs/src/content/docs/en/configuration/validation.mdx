## Primary Commands

Local binary:

```bash
synctv config --config synctv.yaml validate --strict
```

If the service starts but access, authentication, media playback, or Ingress behavior is wrong, start from [Troubleshooting](../../operations/troubleshooting/).

`config validate` reports unknown config-file keys and unsupported `SYNCTV_` environment variables as warnings by default. Use `--strict` for deployment preflight because `synctv serve` uses the same strict unknown-input policy at startup.

## Common Errors

### OPAQUE Secret Is Empty

Meaning: `security.opaque_server_setup_secret` is not configured.

Set the secret:

```bash
export SYNCTV_SECURITY_OPAQUE_SERVER_SETUP_SECRET="$(openssl rand -base64 48)"
```

Save this value in production. Do not regenerate it on every deployment.

### Credential Key Format Is Invalid

`security.credential_encryption_key` must be 64 hexadecimal characters.

Generate:

```bash
openssl rand -hex 32
```

Wrong examples:

- Base64 strings.
- Human passwords.
- Any value whose length is not 64 hex characters.

### CORS Origin Is Invalid

Correct:

```yaml
server:
  cors_allowed_origins:
    - "https://app.example.com"
```

Wrong:

```yaml
server:
  cors_allowed_origins:
    - "https://app.example.com/path"
```

CORS origins cannot include paths.

### WebAuthn Origin Is Invalid

`webauthn.rp_origin` must also be an origin without path, query, or fragment.

### Cluster Enabled but Redis Missing

`cluster.enabled=true` requires Redis.

Set Redis:

```yaml
redis:
  url: "redis://redis:6379"
```

### Cluster Enabled but Cluster Secret Missing

Set the cluster secret:

```bash
export SYNCTV_CLUSTER_SECRET="$(openssl rand -hex 32)"
```

## Compose Debugging

First make sure you got the production Compose files from [Docker Compose Deployment](../../install/docker-compose/#get-production-compose-files), then generated `.env.postgres`, `.env.redis`, and `.env.synctv` in the same directory.

Inspect final Compose config:

```bash
make compose-config
```

Inspect logs:

```bash
make compose-logs SERVICE=synctv
```

If Compose reports a required variable missing, production Compose expects explicit secrets. Return to the repository directory, run `make compose-init`, and fill the root password in `.env.synctv`.

## Helm Debugging

Render the final manifests from the OCI chart:

<Code code={`helm template ${helmChartName} ${helmOciChartReference} \\
  --version ${helmChartVersion} \\
  --namespace synctv \\
  --values my-values.yaml`} lang="bash" />

Inspect runtime ConfigMap:

```bash
kubectl get configmap synctv-config -n synctv -o yaml
```

List Secret keys:

```bash
kubectl get secret synctv-secrets -n synctv -o jsonpath='{.data}' | jq 'keys'
```

Do not paste Secret values into issues or chat.
