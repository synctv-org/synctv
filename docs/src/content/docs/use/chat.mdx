title: 聊天
description: 普通用户如何使用房间聊天，并判断禁言、聊天关闭或实时连接异常。
---

聊天属于房间实时功能。能否发送消息，取决于房间设置和你的 `send_chat_messages` 权限。

## 常见状态

| 现象 | 可能原因 | 你可以做什么 |
| --- | --- | --- |
| 看得到聊天但不能发送 | 房间关闭聊天、你被禁言或没有 `send_chat_messages` | 联系房间管理员 |
| 消息发送后别人看不到 | Realtime 断开、服务端限流或房间状态异常 | 重新进入房间，记录时间和错误 |
| 只有自己收不到新消息 | 浏览器网络、代理或 WebSocket 被断开 | 刷新页面或换网络 |
| 所有人都收不到消息 | 服务端 Realtime、Ingress 或集群事件异常 | 让管理员检查运行状态 |

## 使用建议

- 房间里临时安静一段时间时，优先让房间管理员关闭聊天。
- 只限制单个用户时，使用成员级权限，不要修改整个房间默认设置。
- 不要在聊天里发送密码、token、Cookie、Provider 凭据或 OAuth2 code。
- 提交问题时提供房间 ID、时间、消息内容摘要和错误文本，不要提供敏感值。

聊天通过房间 Realtime 同步。协议细节见 [Realtime API](../../develop/realtime-api/)。
