## 独立 Media Provider Server

这些变量由 `media-provider-server` 二进制读取，不经过主 SyncTV 配置加载器。

| 环境变量 | 含义 |
| --- | --- |
| `PROVIDER_AUTH_SECRET` | 必填，用于 `x-provider-secret` gRPC metadata 的共享密钥 |
| `PROVIDER_LISTEN_ADDR` | Provider gRPC 监听地址，默认 `[::]:50051` |
| `PROVIDER_GRPC_COMPRESSION_ENABLED` | 是否允许 provider server 协商 gzip 压缩，默认 `true` |
