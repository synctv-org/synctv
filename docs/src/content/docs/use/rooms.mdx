房间是一组成员同步观看和聊天的空间。你能否进入房间，取决于房间可见性、密码、审核、游客设置、人数上限和封禁状态。

## 加入房间

<Tabs syncKey="join-room-user">
  <TabItem label="公开或可加入房间" icon="rocket">
    <Steps>
    1. 从房间列表或已有房间入口打开房间。
    2. 如果房间不需要密码和审核，直接加入。
    3. 进入房间后，按你的房间角色获得聊天、播放列表和播放控制权限。
    </Steps>
  </TabItem>
  <TabItem label="需要密码" icon="seti:lock">
    <Steps>
    1. 输入房间密码。
    2. 如果同时需要审核，提交后等待房间管理员处理。
    3. 密码错误时不要反复提交，连续失败可能触发限流或审计。
    </Steps>
  </TabItem>
  <TabItem label="需要审核" icon="approve-check-circle">
    <Steps>
    1. 提交加入请求。
    2. 等待房间管理员或创建者处理。
    3. 被拒绝后如需再次加入，先确认房间规则或联系房间管理员。
    </Steps>
  </TabItem>
</Tabs>

<Aside type="note">
房间创建者、房间管理员、普通成员和游客看到的操作按钮可能不同。这通常是权限模型的结果，不是界面错误。
</Aside>

## 创建房间

如果平台允许普通用户创建房间，创建后先完成这些设置：

1. 填写清晰的房间名称和说明。
2. 决定是否需要密码。
3. 半公开房间开启加入审核。
4. 设置成员上限，避免超过服务或上游媒体源能力。
5. 检查游客和普通成员的默认权限。
6. 用普通成员账号加入验证一次。

如果创建房间需要审核，提交后等待平台管理员处理。审核通过前，房间可能不会出现在公开列表里。

## 加不进房间

| 现象 | 可能原因 | 你可以做什么 |
| --- | --- | --- |
| 提示密码错误 | 密码变更或输入错误 | 向房间管理员确认最新密码 |
| 一直等待审核 | 房间启用了加入审核 | 等待处理，或联系房间管理员 |
| 提示无权限 | 账号未登录、游客关闭、被房间封禁 | 登录账号或联系房间管理员 |
| 房间人数已满 | 达到 `max_members` | 等待成员退出或请求管理员调整上限 |
| 找不到房间 | 房间不可见、已删除或被封禁 | 确认房间入口是否有效，或联系管理员 |

理解房间对象和角色边界，读 [房间概念](../../concepts/rooms/) 和 [权限模型](../../concepts/permissions/)。
