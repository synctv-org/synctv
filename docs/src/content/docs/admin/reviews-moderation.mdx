审核队列用于控制谁能注册、谁能创建房间、谁能加入受控房间。拒绝、封禁和踢出都应写清原因，方便后续审计和申诉。

## 审核类型

| 类型 | 触发场景 | 处理人 |
| --- | --- | --- |
| 用户注册审核 | 注册策略要求人工批准 | 平台管理员 |
| 房间创建审核 | 平台限制普通用户建房 | 平台管理员 |
| 房间加入审核 | 房间启用 `require_approval` | 房间管理员或创建者 |

## 常见命令

```bash
synctv review user-registration list
synctv review user-registration approve <REVIEW_ID>
synctv review user-registration reject <REVIEW_ID> --reason "reason"
```

具体命令族以 [CLI 参考](../../reference/cli/) 为准。

## 治理规则

| 场景 | 推荐处理 |
| --- | --- |
| 注册信息不完整 | 拒绝并写明需要补充的信息 |
| 疑似滥用 | 先拒绝或封禁，再保留证据和原因 |
| 房间违规 | 房间级封禁或限制房间可见性 |
| 单个成员扰乱 | 房间内 kick/ban 或移除权限 |
| 平台级风险用户 | 用户级 ban，影响登录、建房和加入房间 |

批量封禁前先用 `user list` 或 `room member list` 确认目标集合，避免误伤同名、旧账号或不相关成员。
